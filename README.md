# ETF-Data-Tracker
Using Yfinance to find data on ETF performance over the last 10 years
The goal is to see how 5 specific ETFs performed over the last 10 year on certain key metrics, such as
the average annual return and volatility and how the ETFs performed during Bear Markets (such as during 2022).
The code was transfered to an Excel Spreadsheet with additional comments were made.
Python Libraries Used: Yfinance, Numpy, Pandas
